
# YAWCP (Yet Another Windows Command Ping)

An open-source replacement for the standard Windows ping.

Checking availability via check-host using the "ping google.com" command.

## Installing

```javascript
Windows install:
yawcp.exe --install

Linux run:

chmod +x yawcp
./yawcp

```
